# Changesets

Use `pnpm changeset` for every change that affects a published package. The release workflow is the only place allowed to publish packages.

`@consulta-dev/autofill` e `@consulta-dev/qr-engine` pertencem ao mesmo grupo
fixo de versões. Rode `pnpm version-packages`, revise o resultado e use a
mesma versão na tag `v<versão>` antes da workflow de release.
